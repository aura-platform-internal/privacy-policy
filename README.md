# Aura — Política de Privacidade

Página pública da Política de Privacidade da plataforma Aura, mantida pela Filmaro Corp.

## Visualização local

```bash
python -m http.server 8080
```

Acesse `http://localhost:8080`.

## GitHub Pages

O site é publicado a partir da raiz da branch `main` e ficará disponível em:

- Política: `https://aura-platform-internal.github.io/privacy-policy/`
- Exclusão de dados: `https://aura-platform-internal.github.io/privacy-policy/#exclusao-de-dados`

Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.

## Domínio recomendado

O endereço recomendado é `privacidade.aura-platform.filmaro.com.br`.

1. Crie um registro DNS `CNAME` para `privacidade` apontando para `aura-platform-internal.github.io`.
2. Configure o domínio em **Settings → Pages → Custom domain**.
3. Após a validação do DNS, ative **Enforce HTTPS**.

Depois disso, as URLs oficiais serão:

- `https://privacidade.aura-platform.filmaro.com.br/`
- `https://privacidade.aura-platform.filmaro.com.br/#exclusao-de-dados`

O arquivo `CNAME` deve ser adicionado somente depois que o DNS estiver configurado.

## Manutenção

Revise a política sempre que houver mudança nos dados tratados, nas finalidades, nos fornecedores, na retenção ou no canal de contato.
